🏨 دِيار بغداد | Baghdad Stays

Your Guide to a Beautiful Stay in Baghdad 🇮🇶

دِيار بغداد هو موقع إلكتروني يساعد الزوار على اكتشاف خيارات الإقامة في بغداد، من خلال تجربة استخدام عربية أنيقة تجمع بين سهولة البحث وجمال الضيافة البغدادية.

✨ Features

• 🔍 Search for hotels by name or location.
• 📅 Select check-in dates.
• 👥 Choose the number of guests.
• ⭐ Filter accommodation by rating.
• ❤️ Save favorite hotels.
• 🏨 Explore selected hotels in Baghdad.
• 🌆 Discover Baghdad and its neighborhoods.
• 📩 Hotel booking request form.
• 📱 Responsive user interface.
• 🇮🇶 Arabic RTL layout.

🛠️ Technologies Used

• HTML
• CSS
• JavaScript
